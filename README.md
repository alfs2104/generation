# Bootcamp Generation Brasil - Projetos e Exercícios

Este repositório contém as atividades, exercícios práticos e projetos desenvolvidos durante o Bootcamp da **Generation Brasil**.

## 📁 Estrutura do Repositório

* **`generation-logica-programacao/`**: Exercícios práticos de Lógica de Programação desenvolvidos em Portugol Studio.
  * `exercicio1.por`: Algoritmo de ordenação de vetores em ordem decrescente (Bubble Sort).
  * `exercicio2.por`: Algoritmo para análise de dados em vetores (números pares, índices ímpares, soma e média).

## 🛠️ Tecnologias Utilizadas
* **Portugol Studio** / **Portugol Webstudio**
* **Git & GitHub**
